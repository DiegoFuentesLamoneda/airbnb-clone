# Capturas de referencia (flujo de visión → especificación)

Estas capturas son la fuente de las especificaciones de componentes
documentadas en `../context.md` (sección "Especificaciones derivadas de
capturas"). No se usan en la aplicación: son material de diseño.

## Qué capturar

Abre airbnb.com en Chrome, pulsa `F12` → icono de dispositivo (`Ctrl+Shift+M`)
→ escribe `375` x `812` como dimensiones personalizadas. Captura con
`Ctrl+Shift+P` → "Capture full size screenshot".

| Archivo               | Página de Airbnb                                   |
|-----------------------|----------------------------------------------------|
| `01-home.png`         | Portada: navbar, buscador, filtros por categoría y cuadrícula de tarjetas |
| `02-catalog.png`      | Resultados de búsqueda de cualquier ciudad          |
| `03-room-detail.png`  | Detalle de un alojamiento: galería, cabecera, anfitrión, servicios y reserva |

Guarda los tres archivos en esta carpeta con esos nombres exactos.
